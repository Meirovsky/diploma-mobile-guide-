## 1. Project Description

The project aims to develop an intelligent mobile guide that uses image recognition technology to identify landmarks and provide users with useful information about them.

Users can take a photo of a landmark using their mobile device. The application analyzes the image, identifies the landmark, and displays information such as its name, description, and location.

## 2. Problem Statement

People visiting unfamiliar places often have difficulty identifying landmarks and finding reliable information about them.

The proposed mobile application solves this problem by providing an easy and interactive way to recognize landmarks using image recognition technology.

## 3. Actors

- **User:** Takes photos, recognizes landmarks, views information, saves favorites, and checks recognition history.
- **Administrator:** Manages landmark information in the application database.

## 4. Functional Requirements

1. The system shall allow users to register and log in.
2. The system shall allow users to take or upload photos of landmarks.
3. The system shall analyze images using image recognition technology.
4. The system shall identify landmarks.
5. The system shall display information about recognized landmarks.
6. The system shall allow users to save landmarks to favorites.
7. The system shall store recognition history.
8. The administrator shall be able to manage landmark information.

## 5. Non-Functional Requirements

- The application should have a user-friendly interface.
- Image recognition should provide accurate results.
- User data should be stored securely.
- The application should respond to user requests efficiently.
